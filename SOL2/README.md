# 📘 Software Construction 2

This repository contains lab work completed for **Software Construction 2**, focusing on **object-oriented programming in Java** and advanced software design concepts.

The course builds on fundamental programming knowledge and introduces abstraction, modular design, and advanced algorithmic thinking.

---

```txt

```

---

## 🧪 Labs Overview

### 🔹 Lab 1 – Classes & Basic Control Structures

Introduction to object-oriented programming concepts:

* Classes and objects
* Basic control structures
* Simple program design

---

### 🔹 Lab 2 – Encapsulation & Data Management

Focus on core OOP principles and structured programming:

* Encapsulation using private variables
* Getter and setter methods
* Arrays and static variables
* Method design and validation

Applications included:

* Name management system (extended from Lab 1)
* Grade calculator
* Bank account simulation

---

### 🔹 Lab 3 – Inheritance & Polymorphism

Introduction to advanced OOP concepts:

* Class inheritance (e.g., Person → Student)
* Method overriding
* Polymorphism
* Class hierarchies

Applications included:

* Student management system
* Vehicle class hierarchy
* Animal classification system

---

### 🔹 Lab 4 – Recursion, Backtracking & GUI

Focus on advanced algorithms and user interfaces:

* Recursion and problem solving
* Backtracking algorithms
* Two-dimensional arrays
* Event-driven programming (GUI)

Applications included:

* Maze pathfinding
* Game of Life simulation
* GUI calculator
* Game AI logic
* Fractal generation
* (Optional) Sudoku solver

---

## ⚙️ How to Run

Make sure you have **Java installed**.

### Compile

```bash
javac Main.java
```

### Run

```bash
java Main
```

# 🧪 Lab 3 – Interrupt-Based Programming

## 📌 Description

This lab introduces **interrupt-based programming** using the microcontroller’s interrupt system (NVIC).

The goal is to improve previous implementations by replacing **polling and delays** with efficient interrupt-driven execution.

---

## 🔧 Topics Covered

* Interrupts and Interrupt Service Routines (ISR)
* NVIC (Nested Vectored Interrupt Controller)
* Timer-based interrupts
* Event-driven programming

---

## ⚙️ What Was Implemented

* Distance measurement using an ultrasonic sensor without polling
* Use of timer interrupts to control measurement timing
* LED pendulum display updated using interrupts instead of delays

---

## 🎯 Learning Outcome

* Understanding the difference between polling and interrupts
* Writing efficient embedded programs
* Using hardware interrupts to handle real-time events

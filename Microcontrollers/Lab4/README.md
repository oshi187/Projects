# 🧪 Lab 4 – UART Communication

## 📌 Description

This lab introduces **UART (Universal Asynchronous Receiver-Transmitter)** communication between a microcontroller and a PC.

The goal is to send and receive data and use it to control hardware components like LEDs.

---

## 🔧 Topics Covered

* UART communication protocol
* Serial data transmission
* Baud rate and data format configuration
* Sending and receiving data
* Working with ASCII characters

---

## ⚙️ What Was Implemented

* Established communication between microcontroller and PC using a terminal program
* Sent characters from the microcontroller to the PC
* Received strings from the PC and stored them in arrays
* Decoded commands to control LEDs (e.g., turning LEDs on/off)

---

## 🎯 Learning Outcome

* Understanding serial communication between devices
* Configuring UART for data transmission
* Processing user input from a terminal
* Controlling hardware using communication protocols

# 🧪 Lab 5 – Final Project (Interrupt-Based System)

## 📌 Description

This lab is a final project where previous concepts are combined into a complete embedded system.

The main focus is on improving earlier implementations by using **interrupt-based programming** instead of polling.

---

## 🔧 Topics Covered

* Interrupts and ISR (Interrupt Service Routines)
* UART communication
* Ultrasonic sensor (optional use)
* Event-driven programming
* System integration

---

## ⚙️ What Was Implemented

* Developed a custom embedded application using:

  * UART communication **or**
  * Ultrasonic sensor measurement
* Reworked previous implementations to use **interrupts instead of polling**
* Improved system efficiency and responsiveness
* Combined input (communication/sensor) with output (LEDs or display)

---

## 🎯 Learning Outcome

* Designing a complete embedded system
* Using interrupts for real-time behavior
* Improving existing systems for better performance
* Integrating multiple hardware and software components

# 🔌 Microcontrollers

This repository contains lab work completed for the **Microcontrollers** course.

The focus of this course is on **embedded systems programming**, including hardware interaction, real-time processing, and communication between devices using a microcontroller.

---

## 🛠️ Hardware Used

* Microcontroller: **TM4C1294NCPDT (Tiva C Series)**
* Development Board: Tiva C Evaluation Board
* Components:

  * 7-Segment Display
  * Ultrasonic Sensor (HC-SR04)
  * LED Pendulum Module

---

## 🧰 Tools & Environment

* Code Composer Studio (CCS)
* C Programming Language
* Serial Terminal (e.g., PuTTY)

## 🧪 Labs Overview

### 🔹 Lab 1 – GPIO & Display

Introduction to GPIO programming and controlling a 7-segment display using binary and hexadecimal values.

### 🔹 Lab 2 – Sensors & Timing

Distance measurement using an ultrasonic sensor and timers, with output on an LED pendulum.

### 🔹 Lab 3 – Interrupts

Implementation of interrupt-based programming using NVIC to replace polling and improve efficiency.

### 🔹 Lab 4 – UART Communication

Serial communication between microcontroller and PC, including sending, receiving, and decoding commands.

### 🔹 Lab 5 – Final Project

Integration of previous concepts into a complete system using interrupts, UART, or sensor-based input.

---

## ⚙️ How to Build and Run

⚠️ These labs require physical hardware and an embedded development setup.

Typical workflow:

1. Write and modify the program in Code Composer Studio
2. Compile using the embedded toolchain
3. Flash the program to the microcontroller
4. Test using connected hardware (LEDs, sensors, terminal)

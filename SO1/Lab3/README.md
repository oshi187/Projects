# 🧪 Lab 3 – Mathematical Algorithms

## 📌 Description

This lab focuses on implementing mathematical concepts as algorithms.

## 🔧 Topics Covered

* Trigonometric function implementation
* Root finding using the Bisection Method
* Numerical differentiation
* Multi-file C projects (.c and .h files)
* Using external libraries
* Unit testing

## 🎯 Learning Outcome

Understanding how mathematical formulas are translated into computational algorithms.

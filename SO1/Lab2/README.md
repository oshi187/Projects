# 🧪 Lab 2 – Arrays and Functions

## 📌 Description

This lab focuses on arrays, functions, and basic numerical computations.

## 🔧 Topics Covered

* ASCII and binary representation
* String formatting
* Fibonacci sequence
* Array operations:

  * Sum of elements
  * Minimum value
  * Printing arrays
  * Shifting and swapping elements
* Euclidean norm calculation
* Memory size determination

## 🎯 Learning Outcome

Developing problem-solving skills using arrays and modular programming with functions.

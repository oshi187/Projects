# 🧪 Lab 2 – Sorting Algorithms

## 📌 Description

This lab focuses on implementing and understanding different sorting algorithms.

## 🔧 Topics Covered

* Helper functions:

  * Swap elements
  * Print arrays
  * Handle array data
* Sorting algorithms:

  * Bubble Sort
  * Insertion Sort
  * Selection Sort
  * Shell Sort
  * Merge Sort
  * Quick Sort
  * Comb Sort

## 🎯 Learning Outcome

Understanding how different sorting algorithms work and how their approaches differ in efficiency and structure.

# 🧪 Lab 1 – Queues and Lists

## 📌 Description

This lab introduces basic data structures, especially queues, arrays, and lists.

## 🔧 Topics Covered

* Queue implementation
* Array-based data structures
* List-based data structures
* Inserting and removing elements
* Basic data structure operations

## 🎯 Learning Outcome

Understanding how queues and lists store, organize, and process data.

# 🧪 Lab 3 – Hash Tables

## 📌 Description

This lab focuses on hash tables and collision handling techniques.

## 🔧 Topics Covered

* Hash table implementation
* Hashing functions
* Address hashing
* Chained hashing
* Collision counting
* Insert, search, delete, and print operations
* Reading key-value pairs from CSV files

## 🧩 Implemented Functions

### Address Hashing

* Insert or update values
* Search by key
* Delete entries
* Print hash table
* Read values from CSV file

### Chained Hashing

* Insert or update values
* Handle collisions using linked elements
* Store key-value pairs in hash table buckets

## 🎯 Learning Outcome

Understanding how hash tables store data efficiently and how collisions can be handled using different strategies.

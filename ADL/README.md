# 📘 Algorithms and Data Structures

This repository contains lab work completed for the **Algorithms and Data Structures** course.

The course focuses on understanding and implementing important data structures and algorithms in C, including queues, lists, sorting algorithms, searching methods, and hash tables.

---

## 📂 Structure

```txt
Algorithms-and-Data-Structures/
│── Lab1/
│── Lab2/
│── Lab3/
```

---

## 🧪 Labs Overview

### 🔹 Lab 1 – Queues and Lists

Introduction to basic data structures using arrays and linked lists.

### 🔹 Lab 2 – Sorting Algorithms

Implementation and comparison of common sorting algorithms.

### 🔹 Lab 3 – Hash Tables

Implementation of hash tables using address hashing and chained hashing.

---

## ⚙️ How to Compile and Run

Make sure a C compiler such as **GCC** is installed.

### Compile

```bash
gcc main.c -o program
```

For labs with multiple `.c` files:

```bash
gcc main.c file1.c file2.c -o program
```

### Run

```bash
./program
```

On Windows:

```bash
program.exe
```
